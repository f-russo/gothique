# Project information
The project is a gothic literature book archive, pre-seeded with 100 book metadata from The Guterberg Project (think gothic classics like Dracula, The Frankenstein Monster, Jane Eyre, Carmilla and so on).

# User actions
Visitors can:
- create an account
- log into an existing account
- add favorite books to their account
- add public reviews (1-to-5 scale, with text) to books
- manage their favourites list and public reviews list (edit and remove items)

# Styling
The website is styled with a gothic aesthetic.
The color palette is dark and dimly lit, like a vintage bookstore.
UI animations are delicate and evocative.
